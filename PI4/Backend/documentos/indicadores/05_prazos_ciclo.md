# Indicadores — Prazos e Ciclo

Motor do ranking (recebiveis consolidados):

`PMR = recebiveis / DRE - Receita x 365`
`PME = Estoques Diversos / abs(DRE - Custos) x 365`
`PMP = Fornecedores / abs(DRE - Custos) x 365`
`Ciclo Financeiro = PMR + PME - PMP`

Catalogo (so clientes): PMR usa `BAL - Contas a Receber - Clientes`.

`Ciclo Operacional = PME + PMR`

Leitura:

- PMR e PME sobem: mais capital preso, NCG sobe.
- PMP sobe: fornecedores financiam mais; com tesouraria negativa pode ser atraso.
- Ciclo alongado pressiona giro.
