# Indicadores — CAPEX, BAR, DSCR e Divida

## CAPEX

`CAPEX = abs(FLU - Investimentos)`
`CAPEX acumulado = soma anual`

Para o concedente e cumprimento do plano; para o CFO e saida de caixa; para o acionista precisa render ROIC > WACC.

Onde ver: Poder Concedente > Plano de CAPEX.

## BAR

Card: `abs(BAL - Total do Ativo)`
Grafico: Imobilizado + Intangivel − Depreciacao Acumulada − Amortizacao Acumulada.

Onde ver: Ativos Reversiveis.

## DSCR / Cobertura de Juros

Concedente: `EBIT / abs(DRE - Despesas Financeiras)`
Catalogo: `DRE - EBITDA / abs(DRE - Despesas Financeiras)`

< 1,0x nao cobre juros; < 1,5x atencao. Tabela em Solvencia.

## Endividamento, FCFF, FCFE

`Risco = Total do Passivo / Total do Ativo`
`Endividamento = (PC + Exigível LP) / Total do Ativo`
`Dívida Líquida = Empréstimos - Disponível`
`FCFF = FLU - Geração de Caixa - FLU - Investimentos`
`FCFE = FCFF - abs(FLU - Despesas Financeiras)`
